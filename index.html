Faucon — Maquettes UI

Design system & écrans de la phase 3+ · shadcn-vue · Vue 3 (CDN) · Tailwind v4 à l'intégration

v1 · revue design

Maquettes autonomes (HTML + Vue CDN) qui préfigurent l'implémentation Inertia. Chaque composant correspond à un composant shadcn-vue du kit (gratuits, MIT) — le tableau de correspondance ci-dessous sert de spec à l'intégration. Ouvrez les écrans dans le navigateur ; les interactions (⌘K, toasts, éditeur, 2FA) sont fonctionnelles dans la maquette.
